# Relics of Olympus — Recipes

All recipes are normal datapack JSON files (`data/olympus/recipe/*.json`), generated by datagen. Override them with a datapack using the same path. No recipe needs anything from the End.

Recipes are hard **in proportion to the item's power**: base materials cost a little more than vanilla endgame gear, and relics, cores and upgrades cost a lot. `·` = empty slot.

## Materials (in game now)

### Olympian Bronze Ingot ×1
```
G D G     G = Gold Block
C S C     D = Diamond
G D G     C = Copper Block (waxed works too), S = Netherite Scrap
```
Cost: 4 gold blocks, 2 copper blocks, 2 diamonds, 1 netherite scrap.

### Block of Olympian Bronze ×1
9 Bronze Ingots in a full grid. Put the block back in the grid to get the 9 ingots back.

### Divine Smithing Template ×2 (copy)
```
K d K     K = Diamond Block
d T d     d = Diamond
K I K     T = Divine Smithing Template, I = Olympian Bronze Ingot
```
Loot: ~8% in Ancient City and Bastion treasure chests (also End City, once the End is open).

### Blessing Core ×1
```
I D I     I = Olympian Bronze Ingot
D E D     D = Diamond Block
N D N     E = Enchanted Golden Apple, N = Netherite Ingot
```

### Ascension Core ×1
```
K E K     K = Netherite Block
B S B     E = Enchanted Golden Apple
N E N     B = Block of Olympian Bronze, S = Nether Star, N = Netherite Ingot
```

### God Swapper ×1
```
I E I     I = Olympian Bronze Ingot
E T E     E = Echo Shard
D G D     T = Totem of Undying, D = Diamond Block, G = Enchanted Golden Apple
```

### Banner patterns (shapeless, cosmetic)
- **Gorgoneion**: Paper + Gold Block + Spider Eye
- **Thunderbolt**: Paper + Gold Block + Lightning Rod

## Upgrades (smithing table, Phase 2)

| Template slot | Base | Addition | Result |
|---|---|---|---|
| Blessing Core | any Mortal god item | Block of Olympian Bronze | Blessed ★ |
| Ascension Core | any Blessed god item | Block of Olympian Bronze | Ascended ★★ |

The core is used up. Enchantments are kept.

## Craftable god items (Phase 3)

**Progression:** every craftable god item needs a starter relic of the same god as an ingredient (it is used up), so you climb tier by tier: starter relic → craftable relic → legendary.

| Craftable | Needs this starter relic |
|---|---|
| Caduceus | Talaria (Hermes) |
| Spear of Athena | Owl of Athena |
| Forge Hammer | Hammer of Hephaestus |
| Harpe | Helm of Darkness (Perseus wore Hades' helm to slay Medusa) |
| Thyrsus | Goblet of Dionysus |
| Cornucopia | Sickle of Demeter |

### Caduceus
```
D H D     D = Diamond Block
E T E     H = Heavy Core (Ominous Vaults), T = Talaria
R B R     E = Enchanted Golden Apple, R = Breeze Rod, B = Block of Olympian Bronze
```

### Thyrsus
```
G O G     G = Glow Berries, O = Goblet of Dionysus
V S V     V = Vines
D B D     S = Netherite Sword, D = Diamond Block, B = Block of Olympian Bronze
```

### Cornucopia
```
A S A     A = Golden Apple, S = Sickle of Demeter
C H C     C = Golden Carrot, H = Goat Horn
D B D     D = Diamond Block, B = Block of Olympian Bronze
```

### Spear of Athena, Forge Hammer, Harpe (crafting)
```
D R D     R = the starter relic (Owl of Athena / Hammer of Hephaestus / Helm of Darkness)
B W B     W = Trident / Netherite Pickaxe / Netherite Sword
D T D     B = Block of Olympian Bronze, D = Diamond Block, T = Divine Smithing Template
```

### Hoplite Armor (smithing, not a god item)
Divine Smithing Template + Netherite armor piece + Block of Olympian Bronze.

## Kept cheap on purpose
- **Codex of Olympus** (Phase 5): Book + Gold Ingot. It's the guide book; everyone should have one.

## Not craftable
- 12 starter relics: claiming, God Swapper or `/olympus claim|give` only.
- 6 legendaries: boss events only (one of each per server).
