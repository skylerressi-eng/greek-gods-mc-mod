# Relics of Olympus — Recipes

All recipes are normal datapack JSON files (`data/olympus/recipe/*.json`), generated by datagen. Override them with a datapack using the same path.

Legend letters are per recipe. `·` = empty slot.

## Materials

### Olympian Bronze Ingot ×1
```
G C G     G = Gold Block
C S C     C = Copper Block
G C G     S = Netherite Scrap
```

### Olympian Bronze Block ×1
```
I I I
I I I     I = Olympian Bronze Ingot
I I I
```
**Olympian Bronze Ingot ×9** (shapeless): 1 Olympian Bronze Block

### Divine Smithing Template ×2 (duplication, same layout as netherite)
```
D D D     D = Diamond
D T D     T = Divine Smithing Template
D I D     I = Olympian Bronze Ingot
```
Loot: ~8% (config `loot.divineTemplateChance = 0.08`) in Ancient City (main chests), End City treasure and Bastion treasure chests.

### Blessing Core ×1
```
I D I     I = Olympian Bronze Ingot
D E D     D = Diamond Block
I D I     E = Enchanted Golden Apple
```

### Ascension Core ×1
```
N E N     N = Netherite Ingot
B S B     E = Enchanted Golden Apple
N E N     B = Olympian Bronze Block, S = Nether Star
```

### God Swapper ×1
```
I E I     I = Olympian Bronze Ingot
E T E     E = Echo Shard
I E I     T = Totem of Undying
```

## Upgrades (smithing table, custom type `olympus:god_upgrade`)

| Template slot | Base | Addition | Result |
|---|---|---|---|
| Blessing Core | any Mortal god item | Olympian Bronze Ingot | same item, Blessed ★ |
| Ascension Core | any Blessed ★ god item | Olympian Bronze Ingot | same item, Ascended ★★ |

The core is used up. Enchantments, name and legendary data are kept.

## Craftable god items

### Caduceus (crafting)
```
P S P     P = Phantom Membrane (wings)
E B E     S = Shulker Shell (winged cap)
R · R     E = Eye of Ender (the serpents' eyes), B = Olympian Bronze Block, R = Blaze Rod
```
*(symmetric layout: the 2 blaze rods form the staff's forked foot)*

### Thyrsus (crafting)
```
G B G     G = Glow Berries (pinecone tip)
V S V     B = Olympian Bronze Block
V G V     V = Vines, S = Netherite Sword
```

### Cornucopia (crafting)
```
A B A     A = Golden Apple
C H C     B = Olympian Bronze Block, C = Golden Carrot
Y Y Y     H = Goat Horn (any), Y = Hay Bale
```

### Smithing: Divine Smithing Template + base + Olympian Bronze Block

## Not craftable
- 12 starter relics: claiming, God Swapper or `/olympus claim|give` only.
- 6 legendaries: event rewards only (one of each per server).
